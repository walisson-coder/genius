# Gênius

Jogo da memória de cores feito com HTML, CSS e JavaScript.

O jogo mostra uma sequência de cores e o jogador precisa repetir na mesma ordem.
A cada acerto a sequência aumenta em uma cor. A partida termina quando o jogador
erra uma cor ou quando acabam os 2 minutos.

No final dá para digitar um apelido e ver o ranking com as dez melhores
pontuações, que ficam guardadas em uma planilha do Google.

## Como jogar

1. Abra o arquivo `index.html` no navegador.
2. Clique em "Começar".
3. Espere a sequência acender e clique nos botões na mesma ordem.

## Arquivos

- `index.html` - as telas do jogo
- `style.css` - as cores e o layout
- `script.js` - as regras do jogo e o ranking

## Telas

1. Início
2. Jogo
3. Fim de jogo, com o resultado e o campo do apelido
4. Ranking
